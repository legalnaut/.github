Legalnaut reads a whole litigation case file and turns it into a chronology, a map of contradictions, a proof chart and a dossier for every witness. Each line cites the document, the page and the quotation it came from, and one click opens that page with the passage highlighted.

You upload one archive: a ZIP of the file, a mailbox export (.mbox, .pst, .eml, .msg) or a folder of scans. About 100 documents are read, dated and cross-checked in a few minutes.

### What it does with a case file

- **Reads every page once.** OCR on scanned bundles to the last page, transcripts of hearings and voice messages, chat screenshots turned into conversations, DKIM checks on e-mail and EXIF checks on photographs.
- **Builds the chronology.** Dated events from every document on one timeline, a profile for every person, and correspondence statistics counted from the mail headers.
- **Finds where accounts disagree.** Statements are split into claims and each claim is checked against the rest of the file. A conflicting pair stays a suggestion until a lawyer confirms it.
- **Shows what you can prove.** A proof chart sets each issue beside the exhibits that carry it and marks the gaps. Bundles, chronologies and statements of facts export with fixed exhibit numbers.
- **Prepares the hearing.** Witness dossiers, examination outlines and deadlines computed from the provision and the date they run from.
- **Answers with citations.** The AI assistant searches and reads the file before it answers. Every answer and every draft passes a citation check against the records.

The interface runs in English, Polish, German, French, Spanish, Italian, Portuguese, Dutch and Ukrainian, with unlimited users on every plan.
